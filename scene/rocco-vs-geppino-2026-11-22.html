Le voci dei cronisti

Riccardo la prima volta scarica circa 50 MB (meglio col Wi-Fi), poi resta sul telefono. Voci del telefono: per averne una maschile su Android Impostazioni → Accessibilità → Sintesi vocale (o "Output sintesi vocale") → motore Google → ⚙️ → Installa dati vocali → Italiano e scegli una voce maschile. Se il telefono ha solo voci femminili, l'app le rende più gravi.

Esporta

Collega il sito

Serve una sola volta: una "chiave" di GitHub che permette all'app di pubblicare. Resta solo su questo telefono.

  1. Apri github.com → nuova chiave (entra con l'account del sito)
  2. Nome: "app banda"; scadenza: 1 anno
  3. Repository access: Only select repositories → banda-in-bici
  4. Permissions → Repository → Contents: Read and write
  5. Generate token, copia la chiave (inizia con github_pat_) e incollala qui
