# La banda in bici

Scene 3D delle uscite in bici, fatte con three.js.

- `index.html` — La salita dei Prof. (segmento Strava del 22/09/2026, foto satellitare)
- `cave.html` — La banda in bici: salita delle Cave
- `varcaturo.html` — Varcaturo – Lago Patria
- `crea.html` — app che crea la scena 3D da più file GPX (sorgente in `app/`, istruzioni in `CLAUDE.md`)

Strade ed edifici © OpenStreetMap contributors (ODbL). Foto satellitare: Esri, Maxar, Earthstar Geographics.
