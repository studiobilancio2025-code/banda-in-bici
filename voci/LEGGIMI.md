# Voce "Riccardo" della telecronaca

`riccardo.onnx` è la voce italiana maschile **it_IT-riccardo-x_low** del progetto open source Piper
(https://github.com/rhasspy/piper, modelli MIT), addestrata sul dataset M-AILABS
(https://www.caito.de/2019/01/03/the-m-ailabs-speech-dataset/). Campionamento 16 kHz.
La usa `crea.html` per leggere la telecronaca direttamente nel telefono (gratis, senza account).
